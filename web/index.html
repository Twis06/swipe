    Set up your session

    One clean movement

    1. Up = toward the screen.
      Down = toward the palm rest.
    2. Use the pad of one finger. Swipe the same stretch of the left grille.
    3. Position during the countdown. Move once when it says Record.
    4. Lift your finger before returning. Keep speakers silent.

    Quiet and typing trials teach the model what to ignore. Cues are visual only.

    Recording details

    Two-second mono 32-bit float WAV files preserve samples without encoder clipping. An amber high-peak notice alone does not pause recording. Red “possible clipping” indicates repeated flat-topped samples and pauses collection for review. This check can miss other forms of distortion. If it appears during normal swipes, lower the built-in microphone’s Input volume in macOS System Settings → Sound → Input, then check again. Browser echo cancellation, noise suppression, and automatic gain control are requested off; actual settings are saved. This does not guarantee access to unprocessed hardware audio.

    Two shuffled blocks. Each block is tagged separately for later evaluation. Collect another session later for a stronger test.

    The app sends audio only to the local server. If this folder is inside a cloud-synced directory, your sync provider may upload saved recordings.
